# Gold Age – interactive app
1. `npm i && npm run dev` (local) · `npm run build`
2. Deploy: push to GitHub → import in Vercel (framework: Vite). `vercel.json` already allows iframe embedding.
3. Framer: Assets → Code → New Component → paste `framer/TryTheApp.tsx`, drop it on the case-study page and set "App URL" to your Vercel link.
Demo login: any valid email + 4+ char password ("Use demo account" fills it).
